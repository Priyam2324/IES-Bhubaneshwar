# IEEE IES Bhubaneswar Chapter — Official Event Website

The official website developed for the **IEEE Industrial Electronics Society (IES) Bhubaneswar Chapter** event. The production version was deployed on a custom domain for the duration of the event. This repository is an archived copy preserved as a reference of the original work.

🔗 **[Live Demo](https://priyam2324.github.io/IES-Bhubaneshwar/)**

---

## Overview

Designed and developed a fully responsive, multi-section event website for the IEEE IES Bhubaneswar Chapter. The site was built to serve as the primary online presence for the event — providing attendees with all relevant information in a clean, accessible interface.

## Features

- Fully responsive layout across all screen sizes
- Grid-based section structure for organized content presentation
- Sticky navigation bar for seamless scrolling
- Clean, professional design consistent with IEEE branding guidelines

## Built With

- **HTML** — semantic page structure
- **CSS** — custom styling, grid layouts, and responsive design
- **JavaScript** — interactivity and dynamic UI behaviour

## Running Locally

```bash
# Clone the repository
git clone https://github.com/Priyam2324/IES-Bhubaneswar.git

# Open in browser
open index.html
```
